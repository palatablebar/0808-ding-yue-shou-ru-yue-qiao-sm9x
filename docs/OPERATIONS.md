# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。

## 集团合同收入与部门归属

1. 选择「可签发归属样例」或上传九列归属 CSV，在「归属分摊」阶段查看每个席位的区间分摊与部门合计。
2. 月中转移的席位按分钟占比在原部门与新部门之间拆分，任何一方都不独占整月；部门承担金额之和须与合同收入逐分相等（对账差为 0）。
3. 出现 `ASSIGN_OVERLAP`（重叠归属）或 `COVERAGE_GAP`（断档）时，在分组详情的参与记录中按源行号定位，修复来源后重新上传。
4. 对账无差异、无坏行且无阻塞问题时执行批次并签发；同一来源重跑返回同一批次，不会新增第二份归属结果。
5. 在复核证据 JSON 中保存合同收入、部门承担金额、逐席位区间明细与复核意见。
